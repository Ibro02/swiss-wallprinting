## Decisions

- **Device setting first, then the visitor's choice.** No third "system" state in the switch: it shows the theme you see and switches to the other one.
- **localStorage + a head script, not a cookie read on the server:** a cookie would make every page dynamic (no static HTML, slower first byte) for a preference; the script runs before the first paint, so there is no flash either way.
- **Claude's neutrals, the client's accents.** The dark greys are Claude's; magenta and lime stay, because they are the client's logo colours. Claude's orange is not used.
- **One commit on the branch** (the author asked for a separate branch; without a commit the work would follow the checkout back to Phase 6). Not merged, not pushed.

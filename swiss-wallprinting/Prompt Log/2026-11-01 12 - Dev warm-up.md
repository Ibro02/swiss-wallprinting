# 2026-11-01 12 - Dev warm-up

## Prompt

> Yes, add warm-up

## Goal

The author's answer to the offer in [[2026-11-01 11 - Instant page changes]]: after `vp run dev` starts, request every page once, so that the first click on a page in dev does not wait 1.4–1.6 s.

## Result

- **`scripts/dev.ts` (new), `package.json` `dev`: `node scripts/dev.ts`.** The script starts `next dev` (arguments passed on, output unchanged). When the server answers, it requests the nine pages one by one at their Italian addresses, then prints ` ✓ Warm-up: 9 pages compiled in 17.4s` (or ` ⚠ Warm-up: no 200 from …`). It exits with the dev server. Ctrl+C reaches the dev server directly (the same terminal); a SIGTERM is passed on.
- **`scripts/lib/dev-warm-up.ts` (new):** `warmUpPaths()` (one localized path per page in `PAGES`) and `devPort()` (`-p`, `--port`, `--port=`, then `PORT`, then 3000). Tests in `scripts/__tests__/dev-warm-up.test.ts` (the paths equal `localizedPath` of the SEO module).
- **Measured** on a copy of the project in the scratchpad (installed offline from the pnpm store; the author's own dev server held the lock on port 3000 and was not touched), port 3005, Playwright's Firefox, the same clicks as in entry 11:

| Start | Projects | FAQ | Contact | About |
|---|---|---|---|---|
| A: cold, no warm-up | 2122 ms | 1760 ms | 2053 ms | 1573 ms |
| B: restart with the compile cache, no warm-up | 1981 ms | 1508 ms | 2023 ms | 1502 ms |
| C: restart with the warm-up | 528 ms | 213 ms | 270 ms | 212 ms |

  The server log explains B: each first visit after a start spends about 1 s in "generate-params" (Next.js checks the `[locale]` params, the group layout has `dynamicParams = false`) plus 0.4–0.8 s in Next.js itself. The Turbopack compile cache does not keep that, so every restart paid it again; this is the author's profile (1.35–1.6 s).
- **Parallel warm-up rejected:** all pages at once took 11.8 s instead of 17–19 s, but in one of two runs five pages answered 500 (`SyntaxError: Unexpected non-whitespace character after JSON`: Next.js 16.4 read a JSON file that another first visit was writing). One by one: three runs, all 200.
- Checked: `vp run dev --port 3005` reaches `next dev`, and a second `vp run dev` in the same folder exits with code 1 and Next.js's own message.
- **Checks:** `vp check` clean, `vp test` 282 passed. The e2e tests run against the production build and are not affected.
- `CLAUDE.md`: the `vp run dev` command row, the `scripts/` row, and the motion rule's dev numbers.

## Decisions

- **One page at a time**, because of the Next.js race above.
- **HTML requests in one locale:** a page is prepared once for all four locales; the localized path avoids the proxy's redirect.
- The 3D code of the configurator is not warmed: it loads only on the visitor's intent, and a page request does not ask for it.
- No opt-out flag: plain `next dev` stays available as `npx next dev`.

## Decisions

- **Vite+ and Next.js conflict.** Vite+ is for Vite-based frameworks; Next.js builds with Turbopack. The plan recommends Next.js for dev, build, and runtime, and Vite+ for install, check, test, and hooks. The alternative is vinext (Next.js API on Vite); its README says it is not yet ready for every production workload, and its image and font support is partial. Waiting for the author (Q1).
- **Parametric room** instead of scaling the GLB: the "Room Blank" model is a box, so the room is built in code at the exact size with the model's textures (P3).
- **Hero "print reveal"** on the real client photo instead of a stock video, until the client sends a time-lapse (P2).
- **Mobile bottom sheet** for the configurator, because the README's side panel is desktop only (P6). Waiting for the author (Q4).
- **Mock guard:** the production build fails while mock content exists, so mock reviews never go live (P9).
- **Prompt log format** is the same as in the author's stake-house project, so both projects hand over the same way.
- **No git repo yet.** `git init` is part of Phase 0.
